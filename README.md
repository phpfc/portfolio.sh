# Personal Portfolio

A minimalist, terminal-inspired portfolio website showcasing my work and experience.

## Features

- 🖥️ Terminal-inspired design
- 🌓 Dark/Light theme toggle
- 📱 Fully responsive
- ⚡ Fast and lightweight
- 🎯 Clean, professional layout

## Sections

- **About**: Personal information and skills
- **Projects**: Personal projects and open-source work
- **Blog**: Technical articles and thoughts
- **CV**: Professional experience and education

## Tech Stack

- HTML5
- CSS3 (Custom Properties for theming)
- Vanilla JavaScript
- No frameworks or dependencies

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No build process needed.
