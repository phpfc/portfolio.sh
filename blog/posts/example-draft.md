# Example Draft Post

This is an example of a draft post. Since `published: false` in the frontmatter, this post won't appear in the blog list.

## How to Use Drafts

1. Set `published: false` in the frontmatter
2. Work on your content
3. When ready, change to `published: true`

## Markdown Features

You can use all standard markdown features:

- **Bold text**
- *Italic text*
- `Inline code`
- [Links](https://example.com)
